# Mohamed Jegham — Portfolio

Portfolio professionnel bilingue (FR / EN), basé sur le CV.

## Lancer en local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Contenu

Les textes FR/EN sont dans `src/data/content.ts` — modifie ce fichier pour mettre à jour expériences, projets, compétences, etc.
